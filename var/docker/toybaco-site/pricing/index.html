よくある質問

料金・契約について。

どのプランを選べばよいですか？＋

無料プランは使いやすさを確かめるために、Lightは人が確認しながら複数の窓口・SNSをまとめるために利用できます。AI自動返信や日々の文章づくりまで活用するならStandardがおすすめです。AI生成はLightの月100回に対し、Standardは月500回。さらに多く使う場合は月2,000回のProを選べます。必要な接続数・同時予約件数・AI生成回数は、料金プランで比較できます。

無料プランはどのように始めますか？＋

メールアドレスの確認で無料プランを開始できます。同じライセンスで有料プランへ移行するときも、データ・接続・担当者・下書きを引き継ぎます。

担当者が増えると料金は変わりますか？＋

全プランで1ライセンス内の担当者登録は人数無制限です。担当者数による追加料金はありません。店舗ごとに導入する場合は、それぞれに1ライセンスが必要です。店舗ごとにプランを選べますが、AI枠は店舗間で共有しません。

接続数と投稿予約数は何を数えますか？＋

接続枠は媒体の種類数ではなく、実際に接続する受信箱・投稿アカウントの数です。同じInstagramを受信と投稿に使う場合は、それぞれ1接続を使います。利用できる媒体は提供元の審査状況・アカウント種別・店舗の権限で異なります。 投稿予約数は投稿先ごとの同時予約上限で、月間の投稿数ではありません。公開すると次の予約用の枠が空きます。

AI生成回数はメッセージ数ですか？＋

いいえ。返信案・投稿文・自動返信など、対象となるAI生成で共有する枠です。一般のメッセージ受信数・手動返信数ではありません。人が確認するAI支援は全プラン、自動返信は通常Standard以上で利用できます。

AI枠はいつ更新されますか？繰り越せますか？＋

無料プランは登録日起算、有料月払いは請求期間に連動して月ごとに更新します。年払いでもAI枠は契約の基準日から毎月付与され、年間分の一括付与ではありません。通常月枠は繰り越せません。

AI枠を使い切ったらどうなりますか？＋

通常枠と有効な追加残高を使い切ると対象のAI生成は停止します。手動での返信・投稿は引き続き行えます。Standard・Proでは500回 5,500円（税別）の追加パックを購入できます。自動購入はありません。

追加パックの有効期限と下位変更後の扱いは？＋

決済成功から90日間有効です。通常枠から先に使い、複数パックは期限が近いものから使います。下位プランや無料プランへ戻っても、期限内の残高は人が確認する返信案・投稿文に使えます。追加パックだけで自動返信の権利は増えません。再購入にはStandard・Proが必要です。

AI自動返信の体験はいつ始まりますか？＋

無料プラン・ライトでは、準備完了後にオーナーが明示的に開始してから14日、または100回の先に到達するまで体験できます。1ライセンスにつき1回です。体験は、IMAP で接続したメール受信箱で行います。Gmail / Microsoft の直接接続は提供元の審査完了後に順次開放します。無料プランの通常月20回とは別の体験枠で、自動課金はありません。接続解除や利用者による中断で期限は延びません。Standard・Proへの移行で体験を終了し、残りの体験枠は持ち越しません。

年払いの支払額と契約期間は？＋

年払いは月額の10%割引で1年分を一括前払いします。「月額換算」は比較用の金額です。実際に支払う年総額はこのページのプランカードで確認できます。更新停止を申し込まない場合、契約条件に沿って自動更新します。

プラン変更・解約はいつ反映されますか？＋

同じ支払周期の上位変更は差額を日割りで請求し、決済成功後に反映します。今期の追加AI枠も残期間に比例します。下位変更・月払いと年払いの切替・解約は契約期間末に適用します。解約は次回の自動更新を停止し、現在の契約期間末に無料プランへ移行します。期間途中の利用者都合の解約には日割り返金を行いません。法令等に基づく例外は利用規約によります。既存のご契約は契約時の条件を維持します。旧契約を自動で新料金に変更することはありません。

更新時の支払いに失敗した場合は？＋

通常更新は最初の失敗から7日間の猶予があります。下位変更を予約した更新でも、猶予中は変更前プランの接続上限を維持します。AI仮枠も変更前プランの当AI期間を基準に、7日分を日割りで一度だけ付与します。再試行・カード変更で期限や枠は延びません。支払い成功を確認して契約を反映します。未解決で猶予が終わると無料プラン相当へ移行し、未入金と確認できた当該更新請求を取り消します。

無料プランや下位プランで上限を超えるデータは消えますか？＋

超過接続は停止し、対象の原稿・予約は削除と区別して保持・保留します。担当者数は減らしません。再購入だけで保留中の過去予約が自動送信されることはありません。再開には接続・権限の確認と本人による日時の再指定が必要です。

対応媒体はすべて同じ条件で接続できますか？＋

LINEは既存のMessaging APIを使い、必要な設定は管理者へ引き継ぎます。Instagramの受信と投稿は目的ごとに権限を確認します。組織メールでは管理者の同意が必要な場合があります。すべての媒体が無条件に接続できるものではありません。

保存や削除について確認したいときは？＋

保存する情報、AIや連携先での処理、削除の依頼方法は、プライバシーポリシーでご案内しています。既存契約に新しい保存条件を遡って適用しません。

見積書だけの依頼はできますか？＋

はい。ご契約前の概算見積もり・比較検討用の見積書発行に対応します。お問い合わせからご依頼ください。

個別設計プランの最低契約期間はありますか？＋

構成により異なります。契約条件はお見積もり時に書面でご提示し、ご確認のうえで進めます。

補助金・助成金を利用した導入は相談できますか？＋

ご検討中の制度と導入内容を伺い、見積書や必要書類の準備をご案内します。制度ごとの要件に応じて、対象となる内容や申請時期を個別に確認します。

通常プランとの違いは何ですか？＋

定額プランは、共通の機能・利用条件で提供します。個別設計プランは、専用環境・業務カスタマイズ・AIエージェントの最適化・導入運用支援を要件に合わせて構成します。1店舗からご相談いただけ、料金は内容と支援範囲に応じてお見積もりします。

情報の取扱いと削除の依頼はプライバシーポリシーをご確認ください。
