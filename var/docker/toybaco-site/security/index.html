セキュリティとデータ保護

大切な情報を
安心して扱うために。

メールやDMの会話、添付ファイル、SNS投稿の原稿。会社や店舗の日々の業務で扱う情報を守るために、トイバコの取り組みとデータの扱いをご案内します。

国内保管の対象と処理場所を分けて説明します。
通信の中継や連携先サービスでは、国外で処理される場合があります。

データの置き場所

データの保管先と
処理場所。

会話やファイルを保存する場所と、通信やAIを処理する場所は役割が異なります。トイバコ側の保管先と、外部サービスでの処理を分けてご案内します。

詳しい保管先・利用サービス
データの保管
AWS（Amazon Web Services）

トイバコ側のデータベース・保存ファイル・バックアップを、東京リージョンに保管します。

AIによる生成
Amazon Bedrock

返信案・自動返信・投稿文などの生成に利用します。入力と生成処理は東京・大阪の環境で扱い、入力をAIモデルの学習に利用しません。

通信の中継・配信
Cloudflare

通信の中継・配信や不正アクセス対策に利用します。グローバルネットワークで処理するため、国外での処理や一時保存、関連ログの取扱いが生じる場合があります。

利用する外部サービスと情報の取扱いは プライバシーポリシーで詳しくご案内しています。

日々の運用

情報を守るための対策。

データへのアクセス、通信、バックアップ、稼働監視。それぞれの役割に合わせて対策を行っています。

アクセス

アカウントごとのデータ分離

ご契約のアカウントごとにデータを分離し、他の契約アカウントのデータにアクセスできないよう管理しています。分離が機能することを検証し、アクセス権限を管理しています。

通信

通信の暗号化

ブラウザーとトイバコのサーバー間の通信は、HTTPSで暗号化します。ファイアウォールによる不正アクセス対策も行っています。

復旧

自動バックアップと復旧試験

データを自動で継続的にバックアップしています。バックアップからの復旧試験を実施し、データを戻す手順を確認しています。

監視

24時間の自動監視

サーバーの稼働状況を24時間自動で監視し、異常を検知すると運営チームへ通知します。

ご利用時のポイント

安心して
使い続けるために。

  1. ログイン情報は共有しない

    担当者ごとにログイン情報を管理してください。パスワードは他のサービスと使い回さず、第三者に知られないように保管しましょう。

  2. 担当者が変わったら利用者を見直す

    担当者の変更や退職があったときは、引き続き利用する人とアクセスできる範囲を確認してください。

  3. 相談時に認証情報を送らない

    パスワードやアクセストークンなどの認証情報は、チャットやお問い合わせフォームに入力しないでください。

AIとデータ

AIの利用範囲と
データの扱い。

AIによる文章の生成と、自動で返信を送る機能を分けて使えます。生成に使う情報と動作範囲をご案内します。

AIモデルの学習に
利用しません

トイバコのAI機能に入力した情報を、AIモデルの学習に利用しません。

返信を生成するとき
問い合わせ本文、関連するやり取り、登録された業務情報・回答方針を処理します。
投稿文を生成するとき
入力した指示や下書き、登録された業務情報を処理します。

これらに個人情報が含まれる場合、その情報も処理対象になることがあります。

担当者が確認して使う

返信案・投稿文の下書き

  1. AIが下書き
  2. 確認・編集
  3. 送信・公開

AIが作成した内容を確認・編集してから使えます。送信や公開の前に、業務の内容に合っているかを確かめてください。

利用者が明示的に有効にする

AI自動返信

  1. 利用者が有効化
  2. 対象に自動返信

初期状態では自動返信はオフです。有効にした範囲では、担当者の送信前確認を挟まずに返信します。AIの回答には誤りが含まれる場合があるため、回答方針や利用範囲を設定してください。

自動返信は設定で停止できます。
AIによる返信であることを明示し、お客様が人による対応への切り替えを求められるようにしています。

解約・書き出し・削除

ご利用を終えるときの
データについて。

有料プランの解約と、データの書き出し・削除は別の手続きです。ご希望に合わせて窓口へご相談ください。

有料プランの解約
契約期間末に無料プランへ移行します。移行だけで会話や原稿、担当者の登録を削除することはありません。
会話データの書き出し
ご希望に応じて会話データを書き出してお渡しします。書き出しをご希望の場合は、お問い合わせ窓口へご連絡ください。
アカウント・個人情報の削除
削除をご希望の場合は、対象を確認したうえで対応します。保存期間と削除の依頼方法は、プライバシーポリシーをご確認ください。

請求・契約の会計記録など、法令上の保存が必要な情報は残る場合があります。

よくある質問

情報の取扱いについて。

連携時に許可する権限や会話本文の利用など、導入前や運用中に気になることをご確認いただけます。

Q運営会社はどのような目的で情報を扱いますか？

サービスの提供、保守、お問い合わせへの対応、法令に基づく対応など、必要な範囲で取り扱います。ご利用者のお客様の個人情報は、ご契約者からの委託に基づきサービスの提供に必要な範囲で取り扱います。

具体的な利用目的は プライバシーポリシーに記載しています。

Q会話の本文をサービスの品質改善に使いますか？

お客様とのメッセージ本文を、サービスの品質改善やAIモデルの学習に利用しません。サービスの提供やお問い合わせへの対応など、必要な範囲で取り扱います。

QメールやSNSへのアクセス許可はなぜ必要ですか？

問い合わせの受信・返信や、SNS投稿の作成・公開に必要な情報へアクセスするためです。接続に必要な権限は媒体ごとに異なるため、許可する内容と接続するアカウントをご確認ください。

媒体ごとに取得する情報と利用目的を プライバシーポリシーでご案内しています。

Q連携を解除するとデータはどうなりますか？

連携の解除方法と、解除後のデータの扱いは媒体ごとに異なります。トイバコ側での解除と、連携先でのアクセスの取り消しでは、停止のタイミングが異なる場合もあります。

有料プランから無料プランへの移行だけで連携が解除されるわけではありません。各媒体の取扱いは プライバシーポリシーをご確認ください。

Qカード番号はトイバコが取り扱いますか？

有料プランの決済にはStripeを利用します。カード番号はトイバコの運営会社を経由せず、Stripeが処理します。

Qこのサイトのアクセス解析はどのように行いますか？

アクセス解析は、利用者が許可した場合にのみ行います。お問い合わせフォームの氏名・メールアドレス・相談内容や、お客様との会話本文は解析イベントに含めません。

許可したあとも「Cookie設定」から停止できます。Googleによる解析の処理は日本国内に限定されません。詳しくは プライバシーポリシーをご確認ください。
