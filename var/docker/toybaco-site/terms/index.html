利用規約

制定日: 2026年8月25日 / 改定日: 2026年9月6日

この利用規約(以下「本規約」)は、株式会社サイバーリレーションズ(以下「当社」)が提供する問い合わせ一元管理サービス「トイバコ」(以下「本サービス」)の利用条件を定めるものです。契約者は、本規約に同意のうえ本サービスを利用するものとします。

第1条(定義)

  1. 「契約者」とは、本規約に同意し、当社との間で本サービスの利用契約を締結した法人または個人事業主をいいます。
  2. 「利用者」とは、契約者の管理のもとで本サービスを利用する役員・従業員等をいいます。
  3. 「エンドユーザー」とは、LINE・Instagram・Web チャット・メール等のチャネルを通じて契約者との間でメッセージの送受信を行う、契約者の顧客等をいいます。
  4. 「契約者データ」とは、本サービス上で取り扱われる、エンドユーザーとの会話内容、連絡先、その他契約者または利用者が本サービスに登録・送信した一切のデータをいいます。

第2条(利用契約の成立)

  1. 利用契約は、当社所定の方法による申込みに対し、当社が承諾の通知を行った時点で成立します。
  2. 当社は、申込者が過去に本規約違反をした場合、その他当社が不適当と判断した場合、申込みを承諾しないことがあります。

第3条(アカウントの管理)

  1. 契約者および利用者は、自己の責任においてアカウント情報(ID・パスワード等)を管理するものとします。
  2. アカウント情報の管理不十分または第三者の使用等によって生じた損害について、当社は責任を負いません。

第4条(利用料金および支払方法)

  1. 本サービスの利用料金は、当社が別途提示する料金プランに従うものとします。
  2. 契約者は、当社が指定する方法により利用料金を支払うものとします。
  3. 同じ支払周期の上位プランへの変更は、差額を日割りで請求し、決済成功後すぐに反映します。下位プランへの変更と月払い・年払いの切替は、現在の契約期間の終了時に反映し、期間途中の追加請求・返金は行いません。
  4. 変更可能なプラン・料金・適用日は「ご契約内容」でご確認ください。旧契約や追加オプションを含む契約の変更は、お問い合わせください。既存の個別合意がある場合は、その条件を維持します。
  5. 支払われた利用料金は、法令に定めがある場合または当社が別途認めた場合を除き、返金しません。

第5条(禁止事項)

契約者および利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. エンドユーザーの同意なくその個人情報を目的外に利用する行為
  3. 迷惑メッセージ・スパムの送信、その他エンドユーザーの利益を不当に害する行為
  4. LINEヤフー株式会社、Meta Platforms, Inc. 等、連携先プラットフォームの規約に違反する行為
  5. 本サービスの運営を妨害する行為、不正アクセス、リバースエンジニアリング
  6. 本サービスの利用権限を第三者に譲渡・貸与する行為
  7. その他、当社が不適切と合理的に判断する行為

第6条(契約者データの取扱い)

  1. 契約者データに関する権利は契約者に帰属します。
  2. 当社は、本サービスの提供・維持・改善、サポート対応、法令に基づく場合に限り、契約者データを取り扱います。
  3. エンドユーザーの個人情報の取扱いにおいて、契約者は個人情報保護法上の義務(利用目的の特定・通知等)を自ら負うものとし、当社は契約者からの委託に基づきこれを取り扱います。
  4. 当社は、契約者データを国内(AWS 東京リージョン)のサーバーで保管し、外国にある第三者への提供は行いません。

第7条(外部サービスとの連携)

  1. 本サービスは、LINE・Instagram 等の外部サービスと連携します。連携には各外部サービスの規約が適用され、契約者はこれを遵守するものとします。
  2. 外部サービスの仕様変更・提供停止等により本サービスの一部が利用できなくなった場合、当社はその責任を負いません。ただし、当社は代替手段の提供に努めます。

第8条(サービスの変更・中断・終了)

  1. 当社は、契約者への事前の通知をもって、本サービスの内容を変更または終了することができます。
  2. 当社は、保守・障害・天災等やむを得ない場合、本サービスの提供を一時中断することができます。緊急の場合を除き、事前に通知します。

第9条(保証の否認および免責)

  1. 当社は、本サービスに事実上または法律上の瑕疵がないことを保証するものではありません。
  2. 当社の責めに帰すべき事由により契約者に損害が生じた場合、当社は、当該損害発生月から遡って12か月間に契約者が支払った利用料金の総額を上限として賠償責任を負います。ただし、当社に故意または重過失がある場合はこの限りではありません。
  3. メッセージの不着・遅延など外部サービスに起因する損害について、当社は責任を負いません。

第10条(契約期間および解約)

  1. 契約期間はお申し込み時に選択する支払周期(月払いは1か月、年払いは1年)です。期間満了までに解約のお申し込みがない場合、契約時の条件で自動更新します。年払いは1年分の一括前払いです。
  2. 解約はいつでもお申し込みいただけます。次回の更新を停止し、現在の契約期間の終了までご利用いただけます。期間途中の解約による日割り返金はありません。法令に定めがある場合または当社が別途認めた場合は、この限りではありません。
  3. 解約後の契約者データの取扱いは、プライバシーポリシーの定めによります。契約者の希望により、当社所定の方法でデータをエクスポートして提供します。

第11条(規約の変更)

当社は、必要と判断した場合、契約者に事前に通知のうえ本規約を変更することができます。変更後に契約者が本サービスを利用した場合、変更後の規約に同意したものとみなします。

第12条(準拠法・裁判管轄)

本規約は日本法に準拠し、本サービスに関して紛争が生じた場合、福岡地方裁判所を第一審の専属的合意管轄裁判所とします。
