使っている媒体が接続できるか、サイトで判断できますか？

媒体名だけでは判断できません。提供元の審査完了後に順次開放する接続があり、アカウント種別や管理権限も確認が必要です。利用する媒体・アカウントの種類・現在の運用をお問い合わせ時にお知らせください。

接続の設定は誰が行いますか？

管理権限が必要な設定は、利用するアカウントの管理者と確認して進めます。LINEは既存のMessaging APIを使い、必要な設定は管理者へ引き継ぎます。組織メールでは管理者の同意が必要な場合があります。

今使っているメールやLINEの画面も併用できますか？

既存画面との併用や設定への影響は、利用する媒体・接続方法ごとに事前確認が必要です。既存画面で続けたい操作と現在の運用をお知らせください。併用できる範囲や設定への影響を確認してご案内します。

接続前のメールやDMの履歴も確認できますか？

過去の履歴をどこまで扱えるかは、接続前に確認が必要です。利用中の媒体と確認したい履歴の範囲をお知らせください。接続前の履歴をまとめて参照したい場合も、対応範囲を確認してご案内します。

複数のメールアドレスは何接続になりますか？

実際に接続する受信箱の数で数えます。代表メールとサポートメールをそれぞれ接続する場合は2接続です。媒体の種類数ではありません。

フォームや予約サイトに届く連絡も管理できますか？

通知メールの受信方法によって扱える場合があります。通知メールを確認できることと、お客様への返信や予約の変更・確定は別の対応範囲です。利用中のサービスと受信方法をお知らせください。

担当者が増えると料金は変わりますか？

全プランで1ライセンス内の担当者登録は人数無制限です。担当者数による追加料金はありません。店舗ごとに導入する場合は、それぞれに1ライセンスが必要です。

AIを使わずに返信できますか？

できます。担当者が手動で返信したり、定型文を使ったりできます。AIの返信案は必要なときに使い、内容を確認・編集してから送信します。
