LINE公式アカウントを
複数人・パソコンで管理する方法。

LINE公式アカウントは、追加費用なしで複数人・複数端末から管理できます。公式機能でのやり方と権限の考え方、そして「誰が返すか」まで管理したい場合の方法を解説します。

公開: 2026-06-29 · 更新: 2026-10-02

公式機能だけで、複数人管理はできます

LINE公式アカウントの管理画面(LINE Official Account Manager)には、メンバーを追加する機能が標準で用意されています。費用はかからず、人数を追加してもLINE側の料金は変わりません。パソコンのブラウザからも、スマホの管理アプリからも同じアカウントを操作できます。

  • 手順: 管理画面の「設定 > 権限管理」からメンバーのLINEアカウント宛てに招待を送る
  • 権限の種類: 管理者(すべて操作可)/運用担当者(メッセージ対応・投稿など)等を選べる
  • 同時ログイン: 複数端末からの同時利用に対応

公式機能の「できないこと」が、チーム運用のつまずきどころ

複数人でログインできるようになっても、次の3つは公式機能では解決しません。

  • 担当の割り当てができない — 誰がどの問い合わせを返すのか決まらず、「誰かが返すだろう」で返信漏れが起きます
  • 対応状況の管理がない — どの会話が未対応で、どれが完了かを一覧できません
  • LINE以外は別画面 — Instagram のDM・メール・Webチャットは、それぞれのアプリを開く必要があります

接続したLINE公式アカウントをメールやInstagram DMとまとめて確認・返信する機能は、トイバコの問い合わせ管理で詳しく紹介しています。

よくある質問

QLINE公式アカウントの複数人管理に料金はかかりますか？▾
かかりません。LINE公式アカウントの権限管理機能は無料で、メンバーを追加してもLINE側の料金は変わりません。
QいまのLINE公式アカウントをトイバコに接続すると、友だちリストは消えますか？▾
消えません。アカウントの作り直しは不要で、いまのアカウントをそのまま接続します。友だちリストも過去の設定も引き継がれます。
