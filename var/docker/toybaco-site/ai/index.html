自動返信はスタンダードから。

返信案や投稿文の作成は全プランに含まれます。店舗情報・FAQをもとに文章を準備し、内容を確認してから送信できます。

1店舗ごとの定額料金。全プランでスタッフ数は無制限です。

使い方は2つ

人が確認するAI支援

全プランで返信案・投稿文を作成。内容を確認・編集してから送信します。

お店が設定する自動返信

スタンダード・プロに含まれます。接客中や営業時間外に確認済みFAQに基づく一次対応を行い、不明点は人へ引き継ぎます。

AIは店舗ごとの共通枠

AI枠は一般のメッセージ数ではありません。返信案・投稿文・自動返信などの対象生成で共有し、通常月枠は繰り越しません。年払いでも月ごとに更新します。

接続枠は媒体の種類数ではなく、実際に接続する受信箱・投稿アカウントの数です。同じInstagramを受信と投稿に使う場合は、それぞれ1接続を使います。利用できる媒体は提供元の審査状況・アカウント種別・店舗の権限で異なります。

予約件数は月間の投稿数ではなく、同時に予約しておける件数です。公開すると枠が空きます。LINEは既存のMessaging APIを使い、必要な設定は管理者へ引き継ぎます。Instagramの受信と投稿は目的ごとに権限を確認します。組織メールでは管理者の同意が必要な場合があります。すべての媒体が無条件に接続できるものではありません。

無料プラン・ライトでの自動返信体験

AI自動返信の体験はいつ始まりますか？

無料プラン・ライトでは、準備完了後にオーナーが明示的に開始してから14日、または100回の先に到達するまで体験できます。1ライセンスにつき1回です。体験は、IMAP で接続したメール受信箱で行います。Gmail / Microsoft の直接接続は提供元の審査完了後に順次開放します。無料プランの通常月20回とは別の体験枠です。自動課金はありません。接続解除や利用者による中断で期限は延びません。スタンダード・プロへの移行で体験を終了し、残りの体験枠は持ち越しません。

必要な分を追加

500回 ¥5,500（税別）

税込 ¥6,050。決済成功から90日間有効。スタンダード・プロで購入できる追加枠です。

通常月枠から先に利用します。下位変更・無料プラン復帰後も期限内の残高は手動支援に利用できます。自動返信の権利は付かず、自動購入もありません。

データの取扱い

AIの案には誤りが含まれることがあります。人が確認して送る運用と、自動返信の対象範囲を設定する運用を区別してください。処理地域・入力情報の扱いはプライバシーポリシーをご確認ください。
