お支払い方法

クレジットカード(Visa / Mastercard / JCB / American Express ほか)または銀行振込(請求書払い)。

お支払い時期

  • クレジットカード: お申し込み時に初回料金(該当する場合は初期設定費用を含む)を決済し、以後は選択した支払周期の更新日に自動決済します。月払いは毎月、年払いは毎年1年分を一括でお支払いいただきます。
  • 銀行振込: 請求書に記載する支払期限(発行から10日以内)までにお支払いください。振込手数料はお客様のご負担となります。

役務の提供時期

決済完了(銀行振込の場合は入金確認)後、原則1営業日以内にアカウント開通のご案内をお送りします。

プラン変更について

同じ支払周期の上位プランへの変更は、差額を日割りで請求し、決済成功後すぐに反映します。下位プランへの変更と月払い・年払いの切替は、現在の契約期間の終了時に反映し、期間途中の追加請求・返金は行いません。

変更可能なプラン・料金・適用日は「ご契約内容」でご確認ください。旧契約や追加オプションを含む契約の変更は、お問い合わせください。既存の個別合意がある場合は、その条件を維持します。

契約期間・解約について

契約期間はお申し込み時に選択する支払周期(月払いは1か月、年払いは1年)です。期間満了までに解約のお申し込みがない場合、契約時の条件で自動更新します。年払いは1年分の一括前払いです。

解約はいつでもお申し込みいただけます。次回の更新を停止し、現在の契約期間の終了までご利用いただけます。期間途中の解約による日割り返金はありません。法令に定めがある場合は、この限りではありません。詳細は利用規約第10条をご確認ください。
