はじめ方

無料プランで始めて、
同じ店舗で育てる。

メール確認から始め、窓口や投稿先を接続。必要な機能が増えたら、データを引き継いで有料へ進めます。

1店舗ごとの定額料金。全プランでスタッフ数は無制限です。

ご利用開始の3ステップ

01

メールを確認

メール確認で無料プランを開始。カード登録は不要です。

02

窓口・投稿先を接続

媒体と利用目的を選び、必要な権限を確認します。管理者の作業が必要な場合は引き継ぎます。

03

同じ店舗で続ける

AIの案を人が確認して返信・投稿。必要になったらデータを保ったまま有料へ移行できます。

接続の前に確認すること

LINEは既存のMessaging APIを使い、必要な設定は管理者へ引き継ぎます。Instagramの受信と投稿は目的ごとに権限を確認します。組織メールでは管理者の同意が必要な場合があります。すべての媒体が無条件に接続できるものではありません。

提供元の承認や店舗の準備状況により、開始までに必要な作業・時間は異なります。

AI体験は、メール接続の開放後に

AI自動返信の体験はいつ始まりますか？

無料プラン・ライトでは、準備完了後にオーナーが明示的に開始してから14日、または100回の先に到達するまで体験できます。1店舗につき1回です。体験は、トイバコで接続した Gmail または Microsoft のメール受信箱で行います。メールの接続は提供元の審査完了後に順次開放します。無料プランの通常月20回とは別の体験枠です。自動課金はありません。接続解除や利用者による中断で期限は延びません。Standard・Proへの移行で体験を終了し、残りの体験枠は持ち越しません。
