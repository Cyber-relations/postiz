初期設定

初期設定・接続の代行は希望制。お申し込み時に選べます。

接続代行 おすすめ

お申し込み時に選択(希望制)

  • LINE・Instagram・メール・Web チャットの接続をすべて代行
  • お願いするのは、いくつかの画面での承認操作だけ
  • いまのアカウントを作り直さず接続。友だちリストもそのまま
  • 営業時間・不在応答・担当者の初期設定まで一緒に

セルフ設定

追加費用なし

  • 管理画面の「設定 > 受信トレイ」から、画面の案内に沿って接続
  • Web チャットはサイトにタグを1つ貼るだけ
  • つまずいたら、チャットでいつでも質問OK
  • 途中から代行への切り替えもできます
