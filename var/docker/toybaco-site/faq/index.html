無料プランの始め方や 会社・店舗での利用について

Q

無料プランはどのように始めますか？

メールアドレスの確認で無料プランを開始できます。同じライセンスで有料プランへ移行するときも、データ・接続・担当者・下書きを引き継ぎます。

Q

会社や1人での利用にも向いていますか？

会社・店舗のどちらでも、1人でもチームでも利用できます。1ライセンス内の担当者登録に人数制限はなく、担当者が増えても追加料金はかかりません。

Q

登録・メール確認のメールが届かないときは？

登録に使ったメールアドレスの入力、迷惑メールフォルダー、受信設定をご確認ください。見当たらない場合は、登録したメールアドレスと試した日時をお問い合わせ窓口へお知らせください。パスワードやメール確認のリンクは送らないでください。

Q

ログインできないときは？

公式のログイン画面を開き、利用するアカウントと入力内容をご確認ください。改善しない場合は、表示されたメッセージと発生日時を添えてお問い合わせください。パスワードや認証コードは送らないでください。

接続・問い合わせ管理

接続・問い合わせ管理。

9件

メールやDMの接続準備と 問い合わせ対応について

Q

使っているメールやSNSを接続できるか、サイトで判断できますか？

媒体名だけでは判断できません。提供元の審査完了後に順次開放する接続があり、アカウント種別・管理権限・投稿形式にも条件があります。すべての媒体が無条件に接続できるものではありません。

LINEは既存のMessaging APIを使い、必要な設定は管理者へ引き継ぎます。Instagramの受信と投稿は目的ごとに権限を確認し、組織メールでは管理者の同意が必要な場合があります。

利用する媒体・アカウントの種類・現在の運用を、導入時に確認します。

Q

接続や承認の設定は誰が行いますか？

管理権限が必要な設定は、利用するアカウントの管理者と確認して進めます。LINEは既存のMessaging APIを使い、必要な設定は管理者へ引き継ぎます。組織メールでは管理者の同意が必要な場合があります。

投稿の承認を使う場合は、作成担当・確認担当の役割と必要な設定を導入時に確認します。

Q

今使っているメールやLINEの画面も併用できますか？

既存画面との併用や設定への影響は、利用する媒体・接続方法ごとに事前確認が必要です。既存画面で続けたい操作と現在の運用をお知らせください。併用できる範囲や設定への影響を確認してご案内します。

Q

接続前のメールやDMの履歴も確認できますか？

過去の履歴をどこまで扱えるかは、接続前に確認が必要です。利用中の媒体と確認したい履歴の範囲をお知らせください。接続前の履歴をまとめて参照したい場合も、対応範囲を確認してご案内します。

Q

複数のメールアドレスは何接続になりますか？

実際に接続する受信箱の数で数えます。代表メールとサポートメールをそれぞれ接続する場合は2接続です。媒体の種類数ではありません。

同じInstagramを受信と投稿に使う場合も、受信箱と投稿先の枠をそれぞれ1接続使います。

Q

フォームや予約サイトに届く連絡も管理できますか？

通知メールの受信方法によって扱える場合があります。通知メールを確認できることと、お客様への返信や予約の変更・確定は別の対応範囲です。利用中のサービスと受信方法をお知らせください。

Q

メールやSNSへのアクセス許可はなぜ必要ですか？

問い合わせの受信・返信や、SNS投稿の作成・公開に必要な情報へアクセスするためです。接続に必要な権限は媒体ごとに異なるため、許可する内容と接続するアカウントをご確認ください。

媒体ごとに取得する情報と利用目的を プライバシーポリシーでご案内しています。

Q

連携を解除するとデータはどうなりますか？

連携の解除方法と、解除後のデータの扱いは媒体ごとに異なります。トイバコ側での解除と、連携先でのアクセスの取り消しでは、停止のタイミングが異なる場合もあります。

有料プランから無料プランへの移行だけで連携が解除されるわけではありません。各媒体の取扱いは プライバシーポリシーをご確認ください。

Q

接続できない・連絡が届かないときは？

利用している媒体・アカウントと、管理権限がある方を確認してください。提供元の審査・接続の開放状況も確認が必要です。

解決しない場合は、発生日時・表示されたメッセージ・現在の運用をお問い合わせ窓口へお知らせください。既存設定の変更や連携解除は、影響を確認してから進めてください。

SNS投稿管理。

7件

写真・動画の準備 予約件数と投稿先について

Q

静止画だけでなく、動画も予約投稿できますか？

用意した動画を、対応するSNSへ日時を指定して予約投稿できます。トイバコで動画そのものを作成・編集する機能を示すものではありません。使える動画形式・公開設定・アカウントの条件はSNSごとに異なり、接続は審査完了後に順次開放します。利用したい形式は導入時に確認します。

Q

すべてのSNSに同じ画像や動画を投稿できますか？

使える画像・動画や文字数などの条件は媒体によって異なります。共通の下書きをもとに、投稿先ごとの形式に合わせて文面・素材を整えます。使いたい形式の対応範囲は導入時に確認します。

Q

同じSNSのアカウントを複数つなげますか？

接続枠はSNSの種類数ではなく、実際に接続する投稿アカウント数です。同じSNSでも2アカウントを接続する場合は2接続になります。アカウント種別や管理権限などの条件はそれぞれ確認します。

Q

同時予約5件は、月に5件しか投稿できないということですか？

月間の投稿数ではありません。1つの投稿先に同時に予約しておける件数です。予約していた投稿が公開されると枠が空きます。

Q

無料プランで複数のSNSへ投稿できますか？

無料プランの投稿先は1接続です。複数の投稿アカウントをまとめる場合は、投稿先3接続のLight、6接続のStandard・Proから選べます。

Q

問い合わせ管理と一緒に使うと契約が2つ必要ですか？

同じトイバコのライセンス内で利用できます。受信箱と投稿先には別々の接続枠があり、同じInstagramを受信と投稿に使う場合は各1接続を使います。店舗ごとに導入する場合は、それぞれに1ライセンスが必要です。

Q

予約時刻を過ぎても投稿されないときは？

トイバコと投稿先の両方で公開状況を確認し、再投稿の前に公開済みでないかをご確認ください。

解決しない場合は、予約した日時・投稿先・表示された状態をお問い合わせ窓口へお知らせください。画像や動画を使った投稿の場合は、素材の形式も確認します。

AIの使い方・利用枠。

8件

下書き・自動返信と 生成回数や追加枠について

Q

AIを使わずに返信できますか？

できます。担当者が手動で返信したり、定型文を使ったりできます。AIの返信案は必要なときに使い、内容を確認・編集してから送信します。

Q

AIを使わずに投稿文を作れますか？

作れます。担当者が手動で下書きを作成・編集して投稿できます。AIは必要なときに文章づくりを補助する機能で、生成回数は返信案・投稿文・AI自動返信などで共通です。

Q

AI生成回数はメッセージ数ですか？

いいえ。返信案・投稿文・自動返信など、対象となるAI生成で共有する枠です。一般のメッセージ受信数・手動返信数ではありません。人が確認するAI支援は全プラン、自動返信は通常Standard以上で利用できます。

Q

AI枠はいつ更新されますか？繰り越せますか？

無料プランは登録日起算、有料月払いは請求期間に連動して月ごとに更新します。年払いでもAI枠は契約の基準日から毎月付与され、年間分の一括付与ではありません。通常月枠は繰り越せません。

Q

AI枠を使い切ったらどうなりますか？

通常枠と有効な追加残高を使い切ると対象のAI生成は停止します。手動での返信・投稿は引き続き行えます。Standard・Proでは500回 5,500円（税別）の追加パックを購入できます。自動購入はありません。

Q

追加パックの有効期限と下位変更後の扱いは？

決済成功から90日間有効です。通常枠から先に使い、複数パックは期限が近いものから使います。下位プランや無料プランへ戻っても、期限内の残高は人が確認する返信案・投稿文に使えます。追加パックだけで自動返信の権利は増えません。再購入にはStandard・Proが必要です。

Q

AI自動返信の体験はいつ始まりますか？

無料プラン・Lightでは、準備完了後にオーナーが明示的に開始してから14日、または100回の先に到達するまで体験できます。1ライセンスにつき1回です。

体験は、トイバコで接続したGmailまたはMicrosoftのメール受信箱で行います。メールの接続は提供元の審査完了後に順次開放します。

無料プランの通常月20回とは別の体験枠で、自動課金はありません。接続解除や利用者による中断で期限は延びません。Standard・Proへの移行で体験を終了し、残りの体験枠は持ち越しません。

Q

AIの回答や投稿文が意図と違うときは？

AIの下書きは、内容を確認・編集してから送信・公開してください。AI自動返信を利用している場合は、設定で停止し、回答方針や利用範囲を見直してください。

ご相談の際は、個人情報や認証情報を含めない範囲で状況をお知らせください。

料金・契約

料金・契約。

7件

プランの選び方 お支払い・変更・解約について

Q

どのプランを選べばよいですか？

無料プランは使いやすさを確かめるために、Lightは人が確認しながら複数の窓口・SNSをまとめるために利用できます。

AI自動返信や日々の文章づくりまで活用するならStandardがおすすめです。AI生成はLightの月100回に対し、Standardは月500回。さらに多く使う場合は月2,000回のProを選べます。

必要な接続数・同時予約件数・AI生成回数は、料金プランで比較できます。

Q

担当者が増えると料金は変わりますか？

全プランで1ライセンス内の担当者登録は人数無制限です。担当者数による追加料金はありません。店舗ごとに導入する場合は、それぞれに1ライセンスが必要です。

店舗ごとにプランを選べますが、AI枠は店舗間で共有しません。

Q

複数の店舗で使う場合、契約はどうなりますか？

店舗ごとに導入する場合は、各店舗に1ライセンスが必要です。例えば3店舗へそれぞれ導入する場合は3ライセンスとなります。各店舗の担当者は人数制限なく登録できます。受信箱・投稿先の接続数やAI生成回数の上限は、各ライセンスで選んだプランに応じます。

Q

年払いの支払額と契約期間は？

年払いは月額の10%割引で1年分を一括前払いします。「月額換算」は比較用の金額です。実際に支払う年総額は料金プランで確認できます。更新停止を申し込まない場合、契約条件に沿って自動更新します。

Q

プラン変更・解約はいつ反映されますか？

同じ支払周期の上位変更は、差額を日割りで請求し、決済成功後に反映します。今期の追加AI枠も残期間に比例します。

下位変更・月払いと年払いの切り替え・解約は、契約期間末に適用します。解約は次回の自動更新を停止し、現在の契約期間末に無料プランへ移行します。

期間途中の利用者都合の解約には日割り返金を行いません。法令等に基づく例外は利用規約によります。既存契約は契約時の条件を維持し、旧契約を自動で新料金に変更することはありません。

Q

更新時の支払いに失敗した場合は？

通常更新は最初の失敗から7日間の猶予があります。下位変更を予約した更新でも、猶予中は変更前プランの接続上限を維持します。

AI仮枠も変更前プランの当AI期間を基準に、7日分を日割りで一度だけ付与します。再試行・カード変更で期限や枠は延びません。

支払い成功を確認して契約を反映します。未解決で猶予が終わると無料プラン相当へ移行し、未入金と確認できた当該更新請求を取り消します。

Q

無料プランや下位プランで上限を超えるデータは消えますか？

超過接続は停止し、対象の原稿・予約は削除と区別して保持・保留します。担当者数は減らしません。再購入だけで保留中の過去予約が自動送信されることはありません。再開には接続・権限の確認と本人による日時の再指定が必要です。

情報の取扱い アクセス許可と保存・削除について

Q

保存や削除について確認したいときは？

保存する情報、AIや連携先での処理、削除の依頼方法は、プライバシーポリシーでご案内しています。既存契約に新しい保存条件を遡って適用しません。

Q

運営会社はどのような目的で情報を扱いますか？

サービスの提供、保守、お問い合わせへの対応、法令に基づく対応など、必要な範囲で取り扱います。ご利用者のお客様の個人情報は、ご契約者からの委託に基づきサービスの提供に必要な範囲で取り扱います。

具体的な利用目的は プライバシーポリシーに記載しています。

Q

会話の本文をサービスの品質改善に使いますか？

お客様とのメッセージ本文を、サービスの品質改善やAIモデルの学習に利用しません。サービスの提供やお問い合わせへの対応など、必要な範囲で取り扱います。

Q

カード番号はトイバコが取り扱いますか？

有料プランの決済にはStripeを利用します。カード番号はトイバコの運営会社を経由せず、Stripeが処理します。

Q

このサイトのアクセス解析はどのように行いますか？

アクセス解析は、利用者が許可した場合にのみ行います。お問い合わせフォームの氏名・メールアドレス・相談内容や、お客様との会話本文は解析イベントに含めません。

許可したあとも「Cookie設定」から停止できます。Googleによる解析の処理は日本国内に限定されません。詳しくは プライバシーポリシーをご確認ください。
