投稿機能

6つのSNSへ、
1回でまとめて予約投稿。

空き枠・キャンペーン・新メニュー。お店からのお知らせを、Instagram・Google マップ・Facebook・Threads・X・TikTok へまとめて予約投稿。受信箱と同じ画面・同じログインです。

予約公開日時指定でおまかせ

1回の投稿

6アプリ順番に投稿 → 1回書いて、まとめて予約。

  • アプリを6つ開いて、同じ文をコピペ
  • 画像をそれぞれアップし直す
  • 投稿し忘れるチャネルが出る

トイバコなら

1回書いて、まとめて予約

  • 書くのは一度。投稿先にチェックを入れるだけ
  • 日時を指定して予約公開
  • 反応も同じ画面で確認

チャネルごとに文面を書き分けることもできます。

投稿先

投稿先は、6つ。

空き枠・キャンペーン・新メニューのお知らせを、必要なところぜんぶへ。

Instagram

写真とあわせて投稿。予約して、あとはおまかせ。

Google マップ

お店の情報欄へ直接。地図から来るお客様に届く。

Facebook

ページへの投稿もまとめて。書き分けも可能。

Threads

同じ内容をワンチェックで配信。

X

営業時間の変更など、すぐ届けたいお知らせに。

TikTok

動画投稿に対応。お店の様子を若い世代へ。

投稿機能はスタンダードプラン以上に含まれます。投稿数の上限はありません。

承認フロー

承認フロー標準搭載。公開前に本部チェック。

店ごとの言い回しのバラつきも、うっかり投稿も、公開前に止まります。多店舗の本部運用のための機能です(1店舗なら承認なしでそのまま投稿もできます)。

トイバコだけ

Google マップに投稿できる受信箱は、トイバコだけ。

いま新しいお客様の多くは、Google マップでお店を見つけています。Google ビジネスプロフィールへの投稿は、その検索結果に直接届くお知らせ。

問い合わせ対応ツールで Google マップへ投稿できるものは、他にありません※。「受け取る」と「届ける」をひとつにした、トイバコならではの機能です。

※ 複数チャネル問い合わせ一元管理ツールのうち Google ビジネスプロフィール投稿に対応する国内サービスとして(2026年8月時点・自社調べ)

反応の集計

投稿ごとの反応を、同じ画面で自動集計。

どの投稿がどれだけ見られたかを同じ画面で確認。「空き枠のお知らせは木曜が伸びる」がわかれば、次はそこに出すだけです。

X への投稿に関する2つの制限

X は 2026年2月から、投稿1件ごとに費用がかかる仕組みに変わりました(他のチャネルはすべて無料です)。トイバコは「店舗ごとの定額」の約束を守るため、X だけ次の形でご提供します。

  • 本文中のリンクは自動で外します。リンクはプロフィール欄をご利用ください(X はリンク付き投稿の表示が伸びにくいため、もともとの定石でもあります)
  • 反応(いいね・表示回数)の集計は X のみ非対応です。他のチャネルはこれまでどおり見られます

この2つをお願いする代わりに、投稿数の上限なし・追加費用なしで X に投稿できます。
