💇 美容室・サロン

スタッフのスマホから、
お店の受信箱へ。

スタッフ個人のスマホ任せになりがちな LINE の返信を、お店の受信箱に集約。全店舗の LINE・Instagram DM を一元管理し、やり取りの履歴ごと会社の資産にします。

課題と解決

美容室・サロンの3大課題を、この機能で解決。

LINE の返信がスタッフ個人のスマホの中。退職と一緒に、お客様とのつながりも消えてしまう。

会社の受信箱に、履歴ごと集約

お店のアカウントとしてやり取りするので、担当が替わっても履歴はぜんぶ残ります。指名のお客様との会話も、会社の資産に。

施術中は手が離せず、DM に気づくのは閉店後。せっかくの新規のご予約を逃してしまう。

不在応答が受け止め、定型文ですぐ返す

手が離せない時間は自動応答がお出迎え。手が空いたら、予約受付・変更・キャンセルの定型文でサッと返信。AI 自動応答(オプション)なら一次回答までおまかせできます。

Instagram の投稿が店長任せで、気づけば先月で止まっている。

空き枠もキャンペーンも、予約投稿

「今週の空き枠」を Instagram と Google マップへまとめて予約投稿。地図でお店を探す新規のお客様にも届きます。

定型文(10本設定済み)

    お問い合わせありがとうございます。 ご希望の日時・メニュー・指名の有無をお知らせください。空き状況を確認してご案内します。

  • /yoyaku-kakutei

    ご予約を承りました。 ◯月◯日(◯) ◯:◯〜 / メニュー: ◯ / 担当: ◯ 当日お気をつけてお越しください。

  • /yoyaku-henkou

    ご連絡ありがとうございます。ご希望の変更日時をお知らせください。 空き状況を確認して、あらためてご案内します。

  • /yoyaku-cancel

    キャンセルを承りました。ご連絡ありがとうございました。 またのご予約をお待ちしています。
